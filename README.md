<h2>🤖 AI Virtual Assistant using Python</h2>

<p>
A Python-based AI Voice Assistant that listens to human voice commands, converts them into actions, and helps perform various tasks on a computer using Python modules.
</p>

<br>

<h3>🚀 Features</h3>

<ul>
<li>🎤 Voice command recognition</li>
<li>🗣️ Text-to-speech responses</li>
<li>💻 Performs computer operations using voice commands</li>
<li>🌐 Opens websites and applications</li>
<li>⚙️ Uses Python modules for automation</li>
</ul>

<h3>🛠️ Technologies Used</h3>

<ul>
<li>Python</li>
<li>Speech Recognition</li>
<li>Text-to-Speech (TTS)</li>
<li>Python Automation Modules</li>
</ul>

<br>

<h3>▶️ Run the Project</h3>

```bash
git clone https://github.com/mdfaisalkhan/Minor-Project.git
cd Minor-Project
pip install -r requirements.txt
python main.py
```
